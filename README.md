- Four destructible shields with pixel-level erosion · 四座掩体，子弹与炸弹都会像素级侵蚀
- Three alien bomb types (rolling / plunger / squiggly) · 三种炸弹弹道
- Mystery ship with shot-count scoring — the famous 300-point trick · 神秘飞碟按射击次数计分——著名的300分技巧

- Red/white/green cellophane color overlay · 红/白/绿彩罩配色
- Attract-screen gag animations from the original ROM · 待机画面复刻原版ROM彩蛋
- High score saved locally · 最高分本地保存
